# 사육현황 대시보드

돼지 사육현황 엑셀(농장별 사육그룹 단위)을 그대로 읽어 현재 사육두수·육성률·폐사·판매 현황을 한 화면에서 보는 대시보드입니다.

## 실행

```bash
npm install
npm run dev
```

## 구성

- **전체 개요**: 현재 사육두수 / 사육그룹 / 농장 수 / 평균 육성률 / 누적 폐사 / 누적 판매 지표, 농장별 사육두수 순위(막대를 누르면 해당 농장으로 이동), 사육단계별 두수, 월별 전입두수 추이, 검색·구분·상태로 걸러 보는 사육그룹 표
- **농장별 상세**: 농장 지표와 개요(돼지구분·평균 일령·평균 두당체중·누적 전입두수·클레임·번식농장), 그룹별 사육두수, 그룹 현황 표

## 농장 범위

기본 화면은 **관리 농장 16곳**(`src/data/managedFarms.ts`)만 보여주고, 사이드바 상단에서 `전체 농장 30`으로 바꿔 전체를 볼 수 있습니다.
지정 농장 중 `웰빙파주`는 원본 표기인 `웰빙파주(이만기)`로 맞췄고, `파파2`는 이번 스냅샷에 사육그룹이 없어 목록에 없습니다(개요 문구로 표시됩니다).

## 데이터

`src/data/breeding.ts`는 업로드된 사육현황 엑셀에서 생성한 스냅샷(82개 사육그룹 / 30개 농장 / 현재고 30,091두, 기준일 2026-09-02)입니다.
데이터가 갱신되면 같은 컬럼 구조로 이 파일을 다시 생성하면 되고, 화면 로직은 `src/lib/stats.ts`의 파생 지표만 사용합니다.

주요 판정 기준:

- **사육단계**: 현재일령 70일 미만 자돈 / 120일 미만 육성 / 180일 미만 비육 / 그 이상 출하대기
- **상태**: 육성률 95% 이상 정상, 90% 이상 주의, 그 미만 위험
- **평균 육성률**: 최초두수로 가중 평균

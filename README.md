# 다중 농장 관리 대시보드

여러 축산 농장의 사육그룹, 두수, 생산·출하 실적, 사료 재고 현황을 한눈에 확인하는 대시보드입니다.

## 실행

```bash
npm install
npm run dev
```

## 구성

- 전체 개요: 농장 수 / 총 사육두수 / 평균 폐사율 / 주의·위험 그룹 등 핵심 지표, 농장별 두수 비교, 월별 매출 추이, 주의가 필요한 사육그룹 목록
- 농장별 상세: 농장 정보, 수용률, 폐사율, 사료 재고, 월별 출하량·매출 추이, 사육그룹 현황 테이블

현재는 `src/data/farms.ts`의 목업 데이터로 동작하며, 이후 실제 데이터 소스(DB/API)로 교체할 수 있도록 `src/types`로 데이터 모델을 분리해 두었습니다.

## 주간보고 활동 내역 추출

주간보고 엑셀에서 담당자의 주차별 진척사항을 뽑아 `data/weekly_activity_<담당자명>.csv`로 저장합니다.

```bash
pip install openpyxl
python3 scripts/extract_weekly_activity.py 권영제 ~/주간보고.xlsx 2026-08-10
```

인자는 순서대로 담당자명, 엑셀 경로, 주차 시작일(`YYYY-MM-DD`)입니다.

전제하는 엑셀 서식은 주차별로 시트가 하나씩 있는 형태입니다.

| 위치 | 내용 |
| --- | --- |
| 시트명 | `26년8월2주` |
| 3행 | `권영제 8월 2주 주간보고` |
| 5행 | `농장명` \| `전주 진척사항` \| `금주 진척사항` \| `비고` |
| 6행~ | 항목별 내용, 빈 행은 구역 구분 |

- `weekOf`로 시트명을 추정해 대상 시트를 찾습니다(`2026-08-10` → `26년8월2주`). 시트명 규칙이 다르면 `--sheet`로 직접 지정합니다.
- 1열 헤더는 `농장명`과 `이슈사항` 표기를 모두 인식합니다.
- 담당자 열이 없는 서식이라 3행 제목으로 담당자를 확인하고, 다르면 경고만 출력한 뒤 계속 진행합니다.
- 전주·금주 진척사항과 비고가 모두 빈 항목 행은 기본적으로 건너뜁니다. `--keep-empty`로 남길 수 있습니다.
- 같은 `weekOf`로 다시 실행하면 그 주차 행만 새로 교체되고 다른 주차 기록은 유지됩니다.
- `--dry-run`으로 저장 없이 결과만 확인할 수 있습니다.

출력 CSV 컬럼은 `week_of, person, sheet, item, prev_week, this_week, note`이며, 셀 안의 줄바꿈은 그대로 보존합니다(UTF-8 BOM, Excel에서 바로 열립니다).

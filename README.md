# 다중 농장 관리 대시보드

여러 축산 농장의 사육그룹, 두수, 생산·출하 실적, 사료 재고 현황을 한눈에 확인하는 대시보드입니다.

## 실행

```bash
npm install
npm run dev
```

## 구성

- 전체 개요: 농장 수 / 총 사육두수 / 평균 폐사율 / 주의·위험 그룹 등 핵심 지표, 농장별 두수 비교, 월별 매출 추이, 주의가 필요한 사육그룹 목록
- 농장별 상세: 농장 정보, 수용률, 폐사율, 사료 재고, 월별 출하량·매출 추이, 사육그룹 현황 테이블

현재는 `src/data/farms.ts`의 목업 데이터로 동작하며, 이후 실제 데이터 소스(DB/API)로 교체할 수 있도록 `src/types`로 데이터 모델을 분리해 두었습니다.

## 주간보고 활동 내역 추출

주간보고 엑셀에서 담당자별 활동 내역을 뽑아 `data/weekly_activity_<담당자명>.csv`로 저장합니다.

```bash
pip install openpyxl
python3 scripts/extract_weekly_activity.py 권영제 ~/주간보고_0810.xlsx 2026-08-10
```

- 인자는 순서대로 담당자명, 엑셀 경로, 주차 시작일(`YYYY-MM-DD`)입니다.
- 시트 전체를 훑어 `일자 / 담당자 / 구분 / 농장 / 활동내용 / 차주계획 / 비고` 계열 헤더를 자동으로 찾습니다. 헤더 이름은 `일자·날짜·수행일`처럼 표기가 달라도 인식하며, 병합 셀로 날짜가 빈 행은 위 행의 날짜를 물려받습니다.
- 담당자 열이 있으면 해당 담당자 행만 걸러내고, 없으면 시트 전체를 그 담당자의 활동으로 봅니다.
- 같은 `weekOf`로 다시 실행하면 그 주차 행만 새로 교체되고 다른 주차 기록은 유지됩니다.
- `--dry-run`으로 저장 없이 결과만 확인할 수 있고, `--sheet`로 특정 시트만 읽을 수 있습니다.
